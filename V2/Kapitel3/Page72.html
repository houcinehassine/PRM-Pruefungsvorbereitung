6.2.1 Daten laden und Zeitsignale stacken

Zuerst werden die Bearing-Daten geladen, geprüft und in einem gemeinsamen Zeitreihen-Array gestapelt.

Importe

Es werden loadmat, os, SVC, GridSearchCV, skew, kurtosis, glob, numpy und matplotlib importiert.

Google Drive

Pfad

Prüfung

Mit os.listdir wird geprüft, welche Dateien im Ordner vorhanden sind.

Python 

from scipy.io import loadmat
import os
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV
from scipy.stats import skew, kurtosis

import numpy as np

6.2.2 Signale in Fenster aufteilen

Danach wird das gestapelte Signal in 100 Fenster zerlegt.

1
Split definieren

Mit np.array_split(timeseries_array, 100) wird die Zeitreihe in 100 gleichartige Abschnitte geteilt.

2
Fenster erzeugen

Jedes Split-Element repräsentiert ein Zeitfenster der vier Kanäle.

3
Vorbereitung für Features

Diese Fenster dienen anschließend als Basis für die Merkmalsberechnung.

Python 

split_array = np.array_split(timeseries_array, 100)
Output
Fensterung
Das Gesamtsignal wird in 100 Abschnitte zerlegt.

6.2.3 Features berechnen

Aus jedem Fenster werden drei statistische Merkmale berechnet: Standardabweichung, Skewness und Kurtosis.

Std

Für jedes Split wird die Standardabweichung mit split.std(axis=0) berechnet.

Skewness

Die Schiefe wird mit skew(split) bestimmt.

Kurtosis

Die Wölbung wird mit kurtosis(split) berechnet.

Feature-Array

Die Merkmale werden in features_array = np.zeros((100, 4, 3)) gespeichert.

Python 

features_array = np.zeros((100, 4, 3))
for nsplit, split in enumerate(split_array):
    features_array[nsplit, :, 0] = split.std(axis=0)
    features_array[nsplit, :, 1] = skew(split)
    features_array[nsplit, :, 2] = kurtosis(split)
Output
Features
Pro Fenster werden 4 Kanäle mit 3 statistischen Merkmalen beschrieben.

6.2.4 Reshaping – Erklärung und Anwendung

Bevor weitergearbeitet wird, wird erklärt, was reshape bedeutet und wie es hier verwendet wird.

1
Beispielarray

a = np.arange(60).reshape(5, 4, 3) zeigt ein dreidimensionales Array mit 60 Elementen.

2
Reshape

a.reshape(20, 3) verändert die Form auf (20, 3), ohne die Elemente zu ändern.

3
Interpretation

Die Daten werden zeilenweise neu aufgeteilt, aber nicht verändert.

Anwendung

features_array wird mit reshape(400, 3) in eine 2D-Matrix überführt.

Labels

Das Zielarray wird als y = np.array([0, 1, 2, 3] * 100) definiert.

Train/Test Split

Anschließend werden Trainings- und Testdaten mit train_test_split erzeugt.

Grundidee

Die Anzahl der Elemente bleibt gleich; nur die Form ändert sich.

Python 

a = np.arange(60).reshape(5, 4, 3)
print(a)
a.reshape(20, 3)

features_array = features_array.reshape(400, 3)
y = np.array([0, 1, 2, 3] * 100)

X_train, X_test, y_train, y_test = train_test_split(features_array, y)
Output
Reshape
Die Daten bleiben inhaltlich gleich, nur die Form ändert sich.

6.2.5 SVM mit GridSearchCV trainieren

Danach wird eine SVM mit RBF-Kernel und klassenausgleichender Gewichtung trainiert.

SVC

Modell

Es wird SVC(kernel='rbf', class_weight='balanced') verwendet.

Grid

Parametergrid

C wird von 1 bis 50 variiert, gamma über 10 Werte im Bereich von 0.0001 bis 0.005.

Best

Bestes Modell

Nach dem Training wird das beste Modell mit grid.best_estimator_ übernommen.

Python 

model = SVC(kernel='rbf', class_weight='balanced')
param_grid = {
    'C': np.arange(1, 51, 5),
    'gamma': np.linspace(0.0001, 0.005, 10)
}
grid = GridSearchCV(model, param_grid, n_jobs=-1)
grid.fit(X_train, y_train)
print(grid.best_params_)

model = grid.best_estimator_
y_fit = model.predict(X_test)
Output
Grid Search
Die Hyperparameter werden systematisch getestet.
Ergebnis
Das beste Modell wird für die Vorhersage verwendet.

6.2.6 Accuracy berechnen

Zum Schluss wird die Genauigkeit des Modells auf dem Testdatensatz berechnet.

Vorhersage

Mit model.predict(X_test) werden die Testdaten klassifiziert.

Accuracy

accuracy_score(y_test, y_fit) wird zur Bewertung verwendet.

Erwartetes Ergebnis

Die gegebene Ausgabe liegt ungefähr bei 0.95.

Einordnung

Das zeigt eine sehr gute Klassifikationsleistung für die Bearing-Daten.

Fazit: Die Kombination aus statistischen Features, RBF-SVM und GridSearchCV liefert eine hohe Erkennungsrate.
