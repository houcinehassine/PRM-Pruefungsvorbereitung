7.1 Lineare SVR mit zwei \(\varepsilon\)-Werten

Zuerst wird eine lineare Support Vector Regression mit zwei unterschiedlichen \(\varepsilon\)-Werten trainiert.

Daten

Es werden \(m = 50\) Punkte mit einer linearen Beziehung erzeugt: \(y = 4 + 3X + \text{Rauschen}\).

Modelle

Es werden zwei Modelle trainiert: LinearSVR(epsilon=1.5) und LinearSVR(epsilon=0.5).

Idee

Das \(\varepsilon\) bestimmt die Breite des tolerierten Bereichs um die Vorhersage.

Vergleich

Ein größeres \(\varepsilon\) führt zu einem breiteren Tubus und weniger Support Vectors, ein kleineres \(\varepsilon\) zu einer strengeren Anpassung.

Python 

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
m = 50
X = 2 * np.random.rand(m, 1)
y = 4 + 3 * X + np.random.randn(m, 1)

from sklearn.svm import LinearSVR

svmreg1 = LinearSVR(epsilon=1.5, random_state=42)
svmreg2 = LinearSVR(epsilon=0.5, random_state=42)

svmreg1.fit(X, y.ravel())
svmreg2.fit(X, y.ravel())
Output
LinearSVR
Die beiden Modelle unterscheiden sich nur im \(\varepsilon\)-Wert.
Folge
Das \(\varepsilon\) beeinflusst, wie viele Punkte als Support Vectors gelten.

7.2 Support Vectors finden

Support Vectors werden in der Regression über Punkte bestimmt, die außerhalb des \(\varepsilon\)-Tubes liegen.

1
Vorhersage berechnen

Zuerst wird für alle Eingaben die Vorhersage mit svmreg.predict(X) berechnet.

2
Abstand zum Tubus prüfen

Dann wird geprüft, ob der absolute Fehler größer als \(\varepsilon\) ist.

3
Support Vectors markieren

Punkte außerhalb des Tubus werden mit np.argwhere(off_margin) markiert und als Support Vectors gespeichert.

Python 

def find_support_vectors(svmreg, X, y):
    ypred = svmreg.predict(X)
    off_margin = np.abs(y - ypred) > svmreg.epsilon
    return np.argwhere(off_margin)

svmreg1.support_ = find_support_vectors(svmreg1, X, y)
svmreg2.support_ = find_support_vectors(svmreg2, X, y)
Output
Support Vectors
Punkte außerhalb des \(\varepsilon\)-Bereichs bestimmen die Regression.

7.3 SVR plotten mit \(\varepsilon\)-Annotation

Die Regression wird mit Vorhersage, \(\varepsilon\)-Bändern und einer Pfeil-Annotation für \(\varepsilon\) visualisiert.

Vorhersage

Die schwarze Linie stellt \(\hat{y}\) dar.

\(\varepsilon\)-Bänder

Die gestrichelten Linien markieren \(\hat{y} + \varepsilon\) und \(\hat{y} - \varepsilon\).

Support Vectors

Die Punkte außerhalb der Bänder werden hervorgehoben.

Annotation

Im Graphen wird \(\varepsilon\) zusätzlich mit einem Pfeil eingezeichnet.

Python 

def plotsvm_regression(svmreg, X, y, axes=None):
    x1s = np.linspace(axes[0], axes[1], 100).reshape(100, 1)
    ypred = svmreg.predict(x1s)
    plt.plot(x1s, ypred, 'k-', linewidth=2, label=r'$\hat{y}$')
    plt.plot(x1s, ypred + svmreg.epsilon, 'k--')
    plt.plot(x1s, ypred - svmreg.epsilon, 'k--')
    plt.scatter(X[svmreg.support_], y[svmreg.support_], s=180, facecolors='#FFAAAA')
    plt.plot(X, y, 'b.')
    plt.xlabel(r'$x_1$', fontsize=18)
    plt.legend(loc='upper left', fontsize=18)
    plt.axis(axes)
Output
Visuelle Idee
Das Modell zeigt Vorhersage und Toleranzband gemeinsam.
\(\varepsilon\)-Pfeil
Die Annotation macht die Tube-Breite im Plot direkt sichtbar.

7.4 Vergleich der linearen SVR

Zwei lineare SVR-Modelle mit unterschiedlichen \(\varepsilon\)-Werten werden nebeneinander dargestellt.

Python 

fig, axes = plt.subplots(ncols=2, figsize=(9, 4), sharey=True)
plt.sca(axes[0])
plotsvm_regression(svmreg1, X, y, axes=[0, 2, 3, 11])
plt.title(r'$\varepsilon = {:.1f}$'.format(svmreg1.epsilon), fontsize=18)
plt.ylabel(r'$y$', fontsize=18, rotation=0)

eps_x1 = 1
eps_ypred = svmreg1.predict([[eps_x1]])
plt.plot([eps_x1, eps_x1], [eps_ypred, eps_ypred - svmreg1.epsilon], 'k-', linewidth=2)
plt.annotate('', xy=(eps_x1, eps_ypred), xycoords='data',
             xytext=(eps_x1, eps_ypred - svmreg1.epsilon), textcoords='data',
             arrowprops=dict(arrowstyle='-', linewidth=1.5))
plt.text(0.91, 5.6, r'$\varepsilon$', fontsize=20)

plt.sca(axes[1])
plotsvm_regression(svmreg2, X, y, axes=[0, 2, 3, 11])
plt.title(r'$\varepsilon = {:.1f}$'.format(svmreg2.epsilon), fontsize=18)
plt.show()
Output
Vergleich
\(\varepsilon = 1.5\) ist toleranter als \(\varepsilon = 0.5\).

7.5 Nicht-lineare SVR – Poly- und RBF-Kernel

Als nächstes werden nicht-lineare Regressionsmodelle mit Poly- und RBF-Kernel verglichen.

Poly

Polynomialer Kernel

Es werden zwei Modelle mit kernel='poly', degree=2 und unterschiedlichen C-Werten trainiert.

RBF

RBF-Kernel

Danach werden zwei Modelle mit kernel='rbf' und unterschiedlichen C-Werten trainiert.

C

Regulierung

Größeres C bedeutet strengere Anpassung, kleineres C mehr Regularisierung.

Python 

from sklearn.svm import SVR

np.random.seed(42)
m = 100
X = 2 * np.random.rand(m, 1) - 1
y = (0.2 + 0.1 * X + 0.5 * X**2 + np.random.rand(m, 1)).ravel()

svmpolyreg1 = SVR(kernel='poly', degree=2, C=100, epsilon=0.1, gamma='scale')
svmpolyreg2 = SVR(kernel='poly', degree=2, C=0.01, epsilon=0.1, gamma='scale')
svmpolyreg1.fit(X, y)
svmpolyreg2.fit(X, y)

svmreg1 = SVR(kernel='rbf', C=100, epsilon=0.1)
svmreg2 = SVR(kernel='rbf', C=0.01, epsilon=0.1)
svmreg1.fit(X, y)
svmreg2.fit(X, y)
Output
Poly
Der polynomiale Kernel passt eine quadratische Struktur an.
RBF
Der RBF-Kernel kann flexibler auf nichtlineare Muster reagieren.

7.6 Vor- und Nachteile von SVMs

Zum Schluss werden die wichtigsten Vorteile und Nachteile von SVMs zusammengefasst.

Vorteil Erklärung
Höherdimensionale Datensätze SVMs sind sehr effektiv bei hochdimensionalen Daten.
Dim > Datenpunkte Hilft wenn Anzahl der Dimensionen größer als die Anzahl der Datenpunkte ist.
Komputativ effizient Besonders bei kleinen bis mittleren Datensätzen.
Geometrische Interpretation Pädagogisch gut vermittelbar durch Hyperebene und Margin.
Nachteil Erklärung
Sehr große Datensätze Probleme bei vielen Datenpunkten, weil die Kernel-Matrix zu groß wird.
Stark überlappende Klassen Viel Rauschen in den Daten führt zu schlechter Trennung.
Probabilistische Interpretation Nicht möglich – SVM gibt keine Wahrscheinlichkeiten.
Zusammenfassung: SVMs sind gut bei kleiner Datenmenge und hoher Dimension, schlecht bei großen Datensätzen und viel Rauschen. Sie liefern keinen Probability-Output, haben aber eine sehr gute geometrische Interpretierbarkeit.
