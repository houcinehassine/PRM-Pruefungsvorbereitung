Hard vs. Soft Margin

Bei SVMs kann der Margin starr als Hard-Margin oder flexibel als Soft-Margin formuliert werden. Der Hyperparameter de>C steuert dabei den Trade-off zwischen Margin-Größe und Verletzungen.

3.1 Hard-Margin und Soft-Margin

Bei SVMs hat man die Möglichkeit die Margins entweder starr bzw. hard oder weich bzw. soft zu definieren.

Hard-Margin

Große Werte von de>C entsprechen einem Hard-Margin.

In anderen Worten: Datenpunkte innerhalb des Margins sind möglichst nicht erlaubt.

Soft-Margin

Kleine Werte von de>C entsprechen einem Soft-Margin.

In anderen Worten: Datenpunkte dürfen innerhalb des Margins auftauchen.

Leitfrage

Die zentrale Frage lautet: wie viele bzw. zu welchem Ausmaß dürfen Datenpunkte das Margin verletzen?

C als Hyperparameter

de>C ist ein Hyperparameter, der getuned werden muss. Der optimale Wert hängt vom Datensatz ab und muss z.B. via Cross-Validation bestimmt werden.

Merksatz: Große Werte von de>C bedeuten Hard-Margin, kleine Werte bedeuten Soft-Margin.

3.2 Slack-Variable \(\xi\)

Zuerst schauen wir, wo in der Mathematik dieses de>C zu finden ist. Dazu führen wir eine sogenannte Slack-Variable ein.

\(\xi\)

Definition

Wir führen eine sog. Slack-Variable \(\xi\) ein, die bestraft, wenn ein Datenpunkt innerhalb des Margins bzw. auf der falschen Seite liegt.

✓

Folge

Dies ermöglicht uns im Umkehrschluss: Verletzungen des Margins werden zugelassen.

C

Bedeutung von C

Der Parameter de>C versucht also eine Balance bzw. einen Trade-Off zwischen „Größe des Margins" und „Verletzung dessen" herzustellen.

Begriff: Zu diesem Parameter sagt man Regularisierungsparameter.

3.3 Optimierungsproblem mit Slack

Mit der Slack-Variable wird das ursprüngliche Optimierungsproblem erweitert und Verletzungen des Margins werden ausdrücklich erlaubt.

Zielfunktion

\[ \min_{\mathbf{w}, b, \xi} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_i \xi_i \]

Bedingungen

\[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 1 - \xi_i \qquad \text{und} \qquad \xi_i \ge 0 \]

Interpretation

Der Parameter de>C gewichtet die Strafe für Margin-Verletzungen. Je größer de>C, desto stärker wird auf saubere Trennung gedrängt.

Trade-off

Der Optimierer balanciert zwischen möglichst großem Margin und möglichst wenigen Verletzungen.

3.4 Loss Function und Hinge Loss

Die naheliegendste Formulierung einer Loss Function wäre die Accuracy – also: wie gut decken sich Vorhersage und Labels?

1
Accuracy ist ungeeignet

Die Accuracy betrachtet nur das Endergebnis. Sie ist jedoch ungeeignet, da es sich hierbei um ein sog. kombinatorisches Optimierungsproblem handelt.

2
Kontinuierliche Loss Function

Eine kontinuierliche Loss Function ist also anzustreben – mögliche Formulierung: Hinge Loss.

3
Hinge Loss

\[ L(t) = \max\{0, 1 - t\} \quad \text{mit} \quad t = y f(\mathbf{x}) = y(\langle \mathbf{w}, \mathbf{x} \rangle + b) \]

Endgültige Formulierung: \[ \min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_i \max\{0, 1 - y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b)\} \]
Fazit: Hierzu sagt man auch Regularisierung – Margin Maximierung ist also Regularisierung.

3.5 Beispiel: Hard und Soft Margin

Im Beispiel werden zwei SVMs mit unterschiedlichen de>C-Werten auf denselben Datensatz trainiert und miteinander verglichen.

Python 

X, y = make_blobs(n_samples=100, centers=2, random_state=0, cluster_std=0.8)

fig, ax = plt.subplots(1, 2, figsize=(16, 6))
fig.subplots_adjust(left=0.0625, right=0.95, wspace=0.1)

for axi, C in zip(ax, [10.0, 0.1]):
    model = SVC(kernel='linear', C=C)
    model.fit(X, y)
    axi.scatter(X[:, 0], X[:, 1], c=y, s=50, cmap='autumn', edgecolors='gray')
    plot_svc_decision_function(model, axi)
    axi.scatter(model.support_vectors_[:, 0], model.support_vectors_[:, 1],
                s=300, lw=1, facecolors='none')
    axi.set_title('C = {:.1f}'.format(C), size=14)
Output
C = 10.0
Entspricht einem stärkeren Hard-Margin-Verhalten.
C = 0.1
Entspricht einem weicheren Soft-Margin-Verhalten.
Vergleich
Der höhere de>C-Wert erlaubt weniger Verletzungen, der kleinere de>C-Wert toleriert mehr Punkte innerhalb des Margins.
Wichtig: Der optimale Wert von de>C hängt vom Datensatz ab und muss via z.B. Cross-Validation bestimmt werden.
