Bei linearen SVMs wird implizit angenommen, dass die Klassen mit einer geraden Linie getrennt werden können. In diesem Kapitel geht es darum, was bei nicht-linear separierbaren Problemen passiert und wie der Kernel-Trick dabei hilft.

5.1 Nicht-lineare Probleme

Bei unserem Digits-Beispiel haben wir implizit angenommen, dass wir die Klassen linear – also mit einer geraden Linie – trennen können.

Problem

Keine lineare Hyperebene wird die beiden Klassen jemals trennen können.

Folge

Es liegt also ein nicht-linear separierbares Problem vor.

Lösung

SVMs sind in der Lage auch solche Probleme zu lösen.

Prinzip

Projektion der Daten in einen höherdimensionalen Raum!

Kernaussage: Wenn eine lineare Trennung nicht möglich ist, kann die Datenrepräsentation in einen höheren Raum das Problem linear separierbar machen.

5.2 Radial Basis Functions

Eine Möglichkeit eine neue Dimension an unseren Raum hinzuzufügen ist z.B. sogenannte Radial Basis Functions zu verwenden.

RBF

Definition

RBFs sind skalare Funktionen \(\phi(r)\), die nur vom Abstand zum Ursprung abhängen.

2D → 3D

Geometrische Idee

Dadurch machen wir also aus unserem 2D- einen 3D-Datensatz.

→

Auswirkung

Das Problem wird in einer höheren Dimension linear separierbar.

5.3 Beispiel: Projektion mit RBF

Im Beispiel werden nicht linear separierbare Daten erzeugt und dann durch eine zusätzliche Dimension dargestellt.

Python 
de>
from sklearn.datasets import make_circles
from sklearn.svm import SVC

X, y = make_circles(100, factor=.1, noise=.1)
clf = SVC(kernel='linear').fit(X, y)

plt.scatter(X[:, 0], X[:, 1], c=y, s=50, cmap='autumn')
plot_svc_decision_function(clf, plot_support=False)

r = np.exp(-(X**2).sum(axis=1))
X_5d = np.hstack([X, r.reshape(-1, 1)])
print(X_5d[:5])

def plot_3D(elev=30, azim=30, X=X, y=y):
    ax = plt.subplot(projection='3d')
    r = np.exp(-(X**2).sum(axis=1))
    ax.scatter(X[:, 0], X[:, 1], r, c=y, s=50, cmap='autumn', edgecolors='gray')
    ax.view_init(elev=elev, azim=azim)
    ax.set_xlabel('x')
    ax.set_ylabel('y')
    ax.set_zlabel('r')

plt.figure(figsize=(10, 7))
plot_3D()
Output
2D-Ansicht
Die Punkte sind in zwei Ringen angeordnet und mit einer linearen SVM nicht sauber trennbar.
3D-Projektion
Durch \(r = \exp(-\|X\|^2)\) entsteht eine zusätzliche Dimension, die die Trennung erleichtert.

5.4 Kernel-Trick – Projektion in höhere Dimensionen

Diese Projektion in höhere Dimensionen wird durch den sog. Kernel-Trick auf die Spitze getrieben.

1
Implizite Erweiterung

Man kann implizit an jeden der \(N\) Datenpunkte eine zusätzliche Dimension anfügen – ohne diese Projektion wirklich durchzuführen.

2
Lineare Trennung im neuen Raum

In diesem \(N\)-dimensionalen Raum wird dann eine linear separierende Hyperebene gesucht.

3
Rückwirkung auf den Originalraum

Diese lineare Hyperebene im \(N\)-dimensionalen Raum wird im ursprünglichen, niedrigdimensionalen Raum zu einer nicht-linearen Hyperebene.

sklearn: In de>sklearn wird das mittels des Hyperparameters de>kernel='rbf' realisiert.

5.5 RBF-Kernel in sklearn

Das folgende Beispiel zeigt die Nutzung des RBF-Kernels in einer SVC.

Python 
de>
clf = SVC(kernel='rbf', C=1E6)
clf.fit(X, y)

plt.scatter(X[:, 0], X[:, 1], c=y, s=50, cmap='autumn', edgecolors='gray')
plot_svc_decision_function(clf)
plt.scatter(clf.support_vectors_[:, 0], clf.support_vectors_[:, 1],
            s=300, lw=1, facecolors='none')
Output
Ergebnis
Die RBF-SVM erzeugt eine nicht-lineare Entscheidungsgrenze und kann die Daten deutlich besser trennen.

5.6 Multi-Class SVMs

Liegen mehr als zwei Klassen vor, so lässt sich unser obiger Ansatz nicht eins-zu-eins anwenden.

Ansatz

Eine Möglichkeit mehrere Klassen zu unterscheiden: für jede Klassenpaarung einen Klassifikator bzw. eine SVM zu trainieren.

Name

Diesen Ansatz nennt man one-versus-one – im Gegensatz zu one-versus-rest.

Anzahl Modelle

Für \(N\) Klassen müssen dann \[ \frac{N(N-1)}{2} \] SVMs trainiert werden.

Entscheidung

Die Entscheidungsgrenzen ergeben sich dann aus der Kombination aller Klassifikatoren.

Merksatz: Bei Multi-Class-Problemen werden mehrere binäre SVMs kombiniert, und die Klasse mit den meisten Stimmen setzt sich durch.
