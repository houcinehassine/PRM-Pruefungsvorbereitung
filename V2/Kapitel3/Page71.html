6.1 Datensatz laden

Zuerst wird der LFW-Datensatz geladen und seine Struktur überprüft.

Importe

Es werden unter anderem seaborn, fetch_lfw_people, PCA, SVC und GridSearchCV importiert.

Datensatz laden

lfw_people = fetch_lfw_people(min_faces_per_person=70, resize=0.4) lädt die Gesichter mit mindestens 70 Bildern pro Person.

Struktur prüfen

Die Bildform wird mit lfw_people.images.shape geprüft; die Zielnamen kommen aus lfw_people.target_names.

Datensatzumfang

Der Datensatz enthält Bilder von 7 Personen und wird als Bildarray mit Form (1288, 50, 37) betrachtet.

Python 

import seaborn as sns
sns.set()
from sklearn.datasets import fetch_lfw_people
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.model_selection import GridSearchCV
from sklearn.metrics import accuracy_score
from sklearn.decomposition import PCA
from sklearn.svm import SVC

lfw_people = fetch_lfw_people(min_faces_per_person=70, resize=0.4)

print(lfw_people.images.shape)
print(lfw_people.target_names)
Output
Bildform
(1288, 50, 37)
Personen
Es gibt 7 Zielklassen in target_names.

Anschließend werden mehrere Beispielbilder in einer Galerie angezeigt.

Subplots erzeugen

2
Bilder einfügen

fig, ax = plt.subplots(3, 5, figsize=(8, 7))

6.3 Features und Labels vorbereiten

Danach werden Bilddaten, Labels und der Trainings-/Testsplit vorbereitet.

X

Feature Matrix

X = lfw_people.data enthält die flach dargestellten Bildfeatures.

y

Labels

y = lfw_people.target ist das zu prognostizierende Personen-Label.

Split

Train/Test Split

Mit train_test_split wird der Datensatz in Training und Testdaten aufgeteilt.

Python 

n_samples, h, w = lfw_people.images.shape

X = lfw_people.data
y = lfw_people.target
target_names = lfw_people.target_names
print(target_names)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25)
Output
Vorbereitung
Die Daten werden für das Machine-Learning-Training aufgeteilt.

6.4 PCA anwenden

Für die hohe Dimensionalität der Bilddaten wird eine PCA zur Dimensionsreduktion verwendet.

PCA

Es wird eine PCA mit n_components = 150 berechnet.

Whitening

whiten=True wird verwendet, um die Komponenten zu normieren.

Transformation

X_train_pca und X_test_pca entstehen durch pca.transform.

Ziel

Die PCA reduziert die Dimensionalität vor dem SVM-Training.

Python 

print("Computing PCA...\n")
n_components = 150
pca = PCA(n_components=n_components, svd_solver='randomized', whiten=True).fit(X_train)
X_train_pca = pca.transform(X_train)
X_test_pca = pca.transform(X_test)
Output
PCA
Die Gesichter werden in einen kompakteren Merkmalsraum projiziert.

6.5 GridSearchCV – Hyperparameter optimieren

Anschließend wird ein SVM-Klassifikator mit Grid Search auf den PCA-Features trainiert.

1
Parametergrid definieren

C und gamma werden über mehrere Werte hinweg getestet.

2
SVC mit RBF-Kernel

Es wird eine SVC(kernel='rbf') verwendet.

3
Bestes Modell auswählen

Das beste Modell wird über clf.best_estimator_ ausgegeben.

Python 

print("Doing Grid Search...")

param_grid = {
    'C': [0.1, 1, 10, 1e2, 5e2],
    'gamma': [0.0001, 0.0005, 0.001, 0.005, 0.01, 0.1]
}

clf = GridSearchCV(SVC(kernel='rbf'), param_grid, n_jobs=-1)
clf = clf.fit(X_train_pca, y_train)
print(clf.best_estimator_)
Output
Hyperparameter
C und gamma werden systematisch optimiert.

6.6 Quantitative Evaluation

Danach wird die Accuracy auf den Testdaten berechnet.

Vorhersage

Accuracy

Die Modellgüte wird über accuracy_score(y_test, y_pred) gemessen.

Ergebnis

6.7 Qualitative Evaluation – Galerie mit Vorhersagen

Zum Schluss werden die Vorhersagen in einer Galerie mit echten und vorhergesagten Namen angezeigt.

1

plot_gallery

Die Hilfsfunktion zeichnet eine Galerie aus Bildern mit Titeln.

2

title

Die Titel zeigen jeweils vorhergesagten und echten Namen an.

3

prediction_titles

Diese Liste bereitet die Anzeigen für alle Testbilder vor.

Python 

def plot_gallery(images, titles, h, w, n_row=3, n_col=4):
    plt.figure(figsize=(1.8 * n_col, 2.4 * n_row))
    plt.subplots_adjust(bottom=0, left=.01, right=.99, top=.90, hspace=.35)
    for i in range(n_row * n_col):
        plt.subplot(n_row, n_col, i + 1)
        plt.imshow(images[i].reshape(h, w), cmap=plt.cm.gray)
        plt.title(titles[i], size=12)
        plt.xticks(())
        plt.yticks(())

def title(y_pred, y_test, target_names, i):
    pred_name = target_names[y_pred[i]].split()[-1]
    true_name = target_names[y_test[i]].split()[-1]
    return f'predicted: {pred_name}\ntrue: {true_name}'

prediction_titles = [title(y_pred, y_test, target_names, i)
                     for i in range(y_pred.shape[0])]

plot_gallery(X_test, prediction_titles, h, w, n_row=5)
Output
Galerie
Vorhersage und echter Name werden nebeneinander sichtbar gemacht.
