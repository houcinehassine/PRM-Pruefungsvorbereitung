2.1 Trainingsdatensatz

Ausgangspunkt ist ein gelabelter Trainingsdatensatz mit Feature-Vektoren und Klassenlabels.

Formale Darstellung

Der Datensatz besteht aus Paaren \((\mathbf{x}_i, y_i)\) mit \(y_i \in \{-1, 1\}\).

\[ \{(\mathbf{x}_i, y_i)\mid i=1,\ldots,N,\; y_i \in \{-1,1\}\} \]

Bedeutung

Die SVM nutzt diese Daten, um eine Trennfläche zu lernen, die beide Klassen möglichst gut separiert.

Python 
from sklearn.datasets import make_blobs

X, y = make_blobs(n_samples=100, centers=2,
                  random_state=2, cluster_std=1.2)

print("Shape von X:", X.shape)
print("Klassen:", set(y))
Output 
Shape von X: (100, 2)
Klassen: {0, 1}

2.2 Hyperebene

Die Trennfläche wird durch einen Normalenvektor und einen Bias beschrieben.

w

Normalenvektor

Der Vektor \(\mathbf{w}\) steht senkrecht auf der Hyperebene und bestimmt ihre Orientierung.

b

Bias

Der Bias \(b\) verschiebt die Hyperebene vom Ursprung weg.

=0

Hyperebenengleichung

Punkte auf der Hyperebene erfüllen:

\[ \langle \mathbf{w}, \mathbf{x}_i \rangle + b = 0 \]

2.3 Vorzeichen der Punkte

Das Vorzeichen des Ausdrucks entscheidet, auf welcher Seite der Hyperebene ein Punkt liegt.

+
Positive Seite

Ist \(\langle \mathbf{w}, \mathbf{x}_i \rangle + b > 0\), liegt der Punkt in Richtung von \(\mathbf{w}\).

−
Negative Seite

Ist der Ausdruck kleiner als 0, liegt der Punkt entgegengesetzt zu \(\mathbf{w}\).

✓
Klassifikationsregel

Für die Vorhersage verwendet die SVM die Signum-Funktion.

\[ \hat{y}_i = \operatorname{sgn}\!\left(\langle \mathbf{w}, \mathbf{x}_i \rangle + b\right) \]
Python 
from sklearn.svm import SVC

model = SVC(kernel='linear', C=1.0).fit(X, y)
scores = model.decision_function(X[:5])

print("Erste 5 Scores:", scores)
print("Vorhersagen:", model.predict(X[:5]))
Output 
Erste 5 Scores: [ ... ]
Vorhersagen: [ ... ]

2.4 Margin und Abstand

Der Margin ist der Abstand der nächstliegenden Punkte zur Hyperebene. Die SVM maximiert genau diesen Abstand.

Margin-Bedingung

\[ y_i\left(\langle \mathbf{w}, \mathbf{x}_i \rangle + b\right) \geq r \]

Optimierung

\[ \max_{\mathbf{w}, b} \; r \]

2.5 Skalierung und Support Vectors

Damit das Problem lösbar wird, wird \(\mathbf{w}\) nicht normiert betrachtet. Der nächstgelegene Punkt wird als Support Vector genutzt.

1
Skalierung setzen

Für den nächstgelegenen Punkt \(\mathbf{x}_a\) gilt:

\[ \langle \mathbf{w}, \mathbf{x}_a \rangle + b = 1 \]
2
Margin vereinfachen

Der Abstand ergibt sich zu:

\[ r = \frac{1}{\|\mathbf{w}\|} \]

2.6 Endgültiges Optimierungsproblem

Die Margin-Maximierung wird schließlich zu einem quadratischen Optimierungsproblem umgeformt.

Ziel

\[ \max_{\mathbf{w}, b} \frac{1}{\|\mathbf{w}\|} \]

Äquivalente Form

\[ \min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \]
Merksatz: Die SVM sucht nicht die beste beliebige Linie, sondern die mit dem größten Margin. Daraus entsteht das harte Optimierungsproblem.
