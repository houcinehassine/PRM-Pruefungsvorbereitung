Hard- und Soft-Margin

Bei SVMs kann die Margin entweder hart oder weich definiert werden. Der Unterschied besteht darin, ob Punkte innerhalb der Margin oder sogar auf der falschen Seite der Trennlinie erlaubt sind.

Hard Margin

Bei einer Hard-Margin-SVM werden keine Verletzungen der Margin zugelassen. Das funktioniert nur gut, wenn die Daten sauber trennbar sind und wenig Rauschen besitzen.

Soft Margin

Bei einer Soft-Margin-SVM dürfen Datenpunkte innerhalb des Margins liegen oder ihn verletzen. Die Verletzung wird über eine Strafterm kontrolliert und im Training berücksichtigt.

Parameter C

Der Hyperparameter C steuert den Trade-off zwischen großem Margin und Fehlertoleranz. Große Werte entsprechen eher Hard-Margin-Verhalten, kleine Werte eher Soft-Margin-Verhalten.

Praxis

Der optimale Wert von C hängt vom Datensatz ab und sollte z. B. mit Cross-Validation bestimmt werden.

Leitfrage: Wie viele bzw. wie starke Verletzungen des Margins sollen zugelassen werden? Genau das regelt der Parameter C.

Argument C und Slack Variables

Um Margin-Verletzungen zu erlauben, führt man Slack Variables \(\xi_i\) ein. Diese bestrafen Punkte, die innerhalb des Margins liegen oder falsch klassifiziert sind. Dadurch wird aus der harten Margin ein optimierbares Soft-Margin-Problem.

Die Formulierung lautet:

\[ \min_{\mathbf{w}, b, \xi} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_i \xi_i \]

mit den Bedingungen

\[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 1 - \xi_i \quad \text{und} \quad \xi_i \ge 0 \]

Der Parameter C kontrolliert also den Trade-Off zwischen Margin-Größe und Verletzungen. Deshalb nennt man C auch Regularisierungsparameter.

Oprimierung mittels Loss Function

Eine naive Loss Function auf Basis der Accuracy ist ungeeignet, weil sie ein kombinatorisches Optimierungsproblem erzeugen würde. Stattdessen verwendet man eine kontinuierliche Verlustfunktion, meist die Hinge Loss.

\[ L(t) = \max\{0, 1 - t\} \quad \text{mit} \quad t = y f(\mathbf{x}) = y(\langle \mathbf{w}, \mathbf{x} \rangle + b) \]

Daraus ergibt sich das optimierbare Problem:

\[ \min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_i \max\{0, 1 - y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b)\} \]

Das ist die Standardform der Soft-Margin-SVM: Margin-Maximierung und Fehlersanktion werden gemeinsam optimiert.

Gradienten der Zielfunktion

Für die Ableitung muss man fallweise unterscheiden, ob ein Punkt den Margin verletzt oder nicht. Daraus ergeben sich zwei verschiedene Gradientenfälle.

Kein Margin-Verstoß

Wenn \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 1 \] gilt, dann ist die Hinge Loss für diesen Punkt null. Die nötigen Gradienten sind:

\[ \nabla_{\mathbf{w}} E(\mathbf{w},b) = \mathbf{w} \]

\[ \nabla_{b} E(\mathbf{w},b) = 0 \]

Margin-Verstoß

Wenn \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) < 1 \] gilt, dann ist die Hinge Loss aktiv. Die Gradienten lauten dann:

\[ \nabla_{\mathbf{w}} E(\mathbf{w},b) = \mathbf{w} - C \sum_i y_i \mathbf{x}_i \]

\[ \nabla_{b} E(\mathbf{w},b) = -C \sum_i y_i \]

Loss Function in Python

Die Loss Function lässt sich direkt in Python formulieren und auswerten. Für Trainingszwecke wird oft ein normalisiertes oder standardisiertes Datenset verwendet.

Python 
import matplotlib.pyplot as plt
import numpy as np
from sklearn.datasets import make_blobs

# Data and parameters
X, y = make_blobs(n_samples=1000, centers=2, cluster_std=0.1)
X = StandardScaler().fit_transform(X)
w = np.random.rand(X.shape[1])
b = np.random.rand()

def svm_loss_function(X, y, w, b, C):
    penalties = 1 - y * (np.dot(X, w) + b)
    penalties[penalties < 0] = 0
    hinge_loss = C * np.mean(penalties)
    loss = 1 / 2 * np.dot(w, w) + hinge_loss
    return loss

# Definition abrufen:
svm_loss_function(X, y, w, b, 1)
Output

Funktion zur Berechnung der SVM-Loss auf Basis von Gewicht, Bias und C.

Gradienten berechnen

Allein mit der Kostenfunktion kommen wir nicht weit – wir müssen die Gradienten nach \(\mathbf{w}\) und \(b\) berechnen, um ein Gradientenabstiegsverfahren zu implementieren.

Python 
def svm_gradients(X, y, w, b, C):
    m = X.shape[0]
    margins = 1 - y * (X.dot(w) + b)
    active = margins > 0
    dw = w - (C / m) * (X[active].T.dot(y[active]))
    db = -(C / m) * np.sum(y[active])
    return dw, db

# Funktion abrufen
svm_gradients(X, y, w, b, 1)
Output

Gradienten für \(\mathbf{w}\) und \(b\) werden zurückgegeben.

Gradientenabstieg: Algorithmus

Zur Trainingssimulation verwenden wir eine Full-Batch-Version des Gradientenabstiegs. Dabei wird pro Epoche der komplette Datensatz für die Gradientenschätzung genutzt.

>Initialisierung: Randomisiere den Gewichtsvektor \(\mathbf{w}^{(1)}\). >Gradientenschätzung: Berechne \[ \Delta \mathbf{w}^{(i)} = -\eta \nabla \Lambda \big|_{\mathbf{w}^{(i)}} \] mit Lernrate \(\eta\). >Update bis Konvergenz: \[ \mathbf{w}^{(i+1)} = \mathbf{w}^{(i)} + \Delta \mathbf{w}^{(i)} \]

Die Trainingsfunktion speichert zusätzlich die Kostenwerte jeder Epoche, damit der Lernfortschritt später geplottet werden kann.

Python 
def svm_train(X, y, w, b, C, lr, epochs):
    list_of_costs = []
    for epoch in range(epochs):
        dw, db = svm_gradients(X, y, w, b, C)
        w -= lr * dw
        b -= lr * db
        list_of_costs.append(svm_loss_function(X, y, w, b, C))
    return w, b, list_of_costs

w, b, list_of_costs = svm_train(X, y, w, b, 1, 0.01, 1000)
plt.plot(list_of_costs)
plt.xlabel('Epochs')
plt.ylabel('Loss')
Output

Die Loss sinkt typischerweise über die Epochen hinweg.

Trainingsvisualisierung

Mit einer Visualisierungsfunktion lässt sich die gefundene Hyperebene im Feature-Raum darstellen. Dafür wird \(\mathbf{w}\) normalisiert, damit die Gerade in 2D sinnvoll gezeichnet werden kann.

Python 
def plot_decision_line(w, b, x_range):
    fig, ax = plt.subplots(figsize=(6,5))
    xmin, xmax = x_range
    xs = np.linspace(xmin, xmax, 400)
    norm = np.linalg.norm(w)
    w = w / norm
    ys = -(w[0] * xs + b) / w[1]
    ax.plot(xs, ys, linewidth=2, label='decision line')
    ax.set_xlabel('x1')
    ax.set_ylabel('x2')
    ax.legend()
    ax.grid(True)
    return ys

ys = plot_decision_line(w, b, x_range=(X[:, 0].min(), X[:, 0].max()))
plt.scatter(X[:, 0], X[:, 1], c=y)
Output

Die Entscheidungsgerade wird zusammen mit dem Datensatz geplottet.
