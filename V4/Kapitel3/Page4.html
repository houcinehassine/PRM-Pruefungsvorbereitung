4.1 Nichtlineare Probleme

Bei unserem Digits-Beispiel haben wir implizit angenommen, dass die Klassen linear – also mit einer Geraden bzw. Hyperebene – trennbar sind. Was passiert, wenn das nicht der Fall ist?

Lineare Trennung

Wenn eine gerade Hyperebene die Klassen sauber trennt, spricht man von einem linear separierbaren Problem.

Nichtlinear separierbar

Wenn keine lineare Hyperebene die Klassen jemals sauber trennen kann, liegt ein nicht-linear separierbares Problem vor.

SVM-Lösung

SVMs können auch solche Probleme lösen, indem sie Daten implizit oder explizit in einen höherdimensionalen Raum abbilden.

4.2 Beispiel mit Kreisen

Das Kreise-Beispiel zeigt ein klassisches nichtlineares Problem: In der 2D-Ebene kann eine lineare SVC die Klassen nicht trennen.

Python 
from sklearn.datasets import make_circles

X, y = make_circles(100, factor=.1, noise=.1)

from sklearn.svm import SVC

clf = SVC(kernel='linear').fit(X, y)

import matplotlib.pyplot as plt

plt.scatter(X[:, 0], X[:, 1], c=y, s=50, cmap='autumn')
#plot_svc_decision_function(clf, plot_support=False);
Output
Ergebnis: Eine lineare Hyperebene wird die beiden Klassen hier nicht sauber trennen können.

4.3 Idee: Projektion in höheren Raum

Eine Lösung besteht darin, die Daten in einen höherdimensionalen Raum zu projizieren. Dort kann das Problem linear separierbar werden.

Eine Möglichkeit ist die Verwendung von Radial Basis Functions (RBF). RBFs sind skalare Funktionen \(\phi(r)\), die nur vom Abstand zum Ursprung abhängen. Dadurch machen wir aus einem 2D-Datensatz durch eine zusätzliche Dimension einen 3D-Datensatz.

Python 
import numpy as np
r = np.exp(-(X ** 2).sum(axis=1))
X[:5]
# [x_1^2 x_2^2]
(X ** 2)[:5]
# x_1^2 + x_2^2
(X ** 2)[:5].sum(axis=1)
Erklärung

Die neue Spalte \(r\) hängt nur vom Abstand zum Ursprung ab und erweitert den Raum um eine Dimension.

Python 
def plot_3D(elev=30, azim=30, X=X, y=y):
    ax = plt.subplot(projection='3d')
    ax.scatter(X[:, 0], X[:, 1], r, c=y, s=50, cmap='autumn', edgecolors='gray')
    ax.view_init(elev=elev, azim=azim)
    ax.set_xlabel('x')
    ax.set_ylabel('y')
    ax.set_zlabel('r')

plt.figure(figsize=(10, 7))
plot_3D()
Output
Intuition: Was in 2D nicht trennbar ist, kann in 3D linear separierbar sein.
Python 
np.concatenate((X, r.reshape(-1, 1)), axis=1)
Output

Die Spalte \(r\) wird an \(X\) angehängt und erzeugt so den erweiterten Merkmalsraum.

4.4 Kernel-Trick

Der Kernel-Trick treibt diese Idee auf die Spitze: Die Projektion in den höherdimensionalen Raum wird implizit durchgeführt, ohne die neuen Koordinaten explizit auszurechnen.

Implizite Abbildung

Jeder Datenpunkt erhält gedanklich zusätzliche Dimensionen, ohne dass diese direkt konstruiert werden müssen.

Lineare Trennung im Hilbertraum

In diesem höherdimensionalen Raum wird eine lineare Hyperebene gesucht. Im ursprünglichen Raum erscheint diese als nichtlineare Trennlinie.

sklearn

In de>sklearn wird das oft über de>kernel='rbf' realisiert.

Python 
from sklearn.svm import SVC

clf = SVC(kernel='rbf', C=1E6)
clf.fit(X, y)

import matplotlib.pyplot as plt

plt.scatter(X[:, 0], X[:, 1], c=y, s=50, cmap='autumn', edgecolors='gray')

4.5 Mehrklassen-SVMs

Liegen mehr als zwei Klassen vor, lässt sich die binäre SVM nicht direkt einsetzen. Dafür nutzt man Kombinationen mehrerer binärer Klassifikatoren.

One-vs-Rest

Eine Klasse wird gegen alle anderen trainiert.

One-vs-One

Für jede Klassenpaarung wird ein eigener Klassifikator trainiert.

Anzahl der Modelle

Für \(N\) Klassen benötigt One-vs-One insgesamt \(\frac{N(N-1)}{2}\) SVMs.

Zusammenfassung: Die Entscheidungsgrenzen entstehen durch die Kombination aller binären Klassifikatoren. In der Praxis nutzt scikit-learn passende Multiclass-Strategien automatisch.
