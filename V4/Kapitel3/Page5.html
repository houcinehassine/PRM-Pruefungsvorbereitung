Support Vector Regression

SVMs können auch zur Regression verwendet werden. In diesem Fall spricht man von Support Vector Regression (SVR). Diese Seite zeigt die Grundidee, den linearen Fall und den nichtlinearen Fall mit Kernels.

5.1 Definieren und erklären

Support Vector Regression ist die Regressions-Variante der SVM. Statt Klassen zu trennen, sucht man eine Funktion, die möglichst viele Punkte innerhalb eines Toleranzbereichs beschreibt [web:57][web:94].

Grundidee

Gesucht wird eine Hyperebene plus Margin, innerhalb dessen sich so viele Datenpunkte wie möglich befinden.

Penalty-Regel

Datenpunkte außerhalb des Margins führen zu Penalties. Die Bestrafung ist also gegenüber der Klassifikation umgekehrt.

Hyperparameter

Zusätzlich zu C ist epsilon wichtig. Es definiert die Breite der Toleranzzone um die Vorhersage.

Merke: In der SVR gibt es keine klassischen Klassen-Support-Vectors, sondern Punkte außerhalb der \(\varepsilon\)-Zone, die das Modell beeinflussen.

5.2 Problem 1: wenn linear

Zuerst betrachten wir einen linearen Zusammenhang. Die Frage ist: Wie kann eine SVR eine Gerade so platzieren, dass möglichst viele Punkte innerhalb des \(\varepsilon\)-Bandes liegen?

Python 
np.random.seed(42)
m = 50
X = 2 * np.random.rand(m, 1)
y = (4 + 3 * X + np.random.randn(m, 1)).ravel()
Output

5.2.1 Lösungsweg

Für den linearen Fall verwenden wir LinearSVR. Danach bestimmen wir die Punkte außerhalb des \(\varepsilon\)-Bandes als relevante Stützpunkte des Modells [web:57][web:59].

1. Modell instanziieren

Mit LinearSVR(epsilon=...) legen wir die Toleranzzone fest.

2. Trainieren

Mit .fit(X, y) wird das Modell an die Trainingsdaten angepasst.

3. Support Points bestimmen

Punkte außerhalb der \(\varepsilon\)-Zone werden als Support Points markiert.

4. Plotten

Regressionsgerade, \(\varepsilon\)-Bänder und relevante Punkte werden visualisiert.

Python 
from sklearn.svm import LinearSVR

svm_reg1 = LinearSVR(epsilon=1.5, random_state=42)
svm_reg2 = LinearSVR(epsilon=0.5, random_state=42)
svm_reg1.fit(X, y)
svm_reg2.fit(X, y)

def find_support_vectors(svm_reg, X, y):
    y_pred = svm_reg.predict(X)
    off_margin = (np.abs(y - y_pred) >= svm_reg.epsilon)
    return np.argwhere(off_margin)

svm_reg1.support_ = find_support_vectors(svm_reg1, X, y)
svm_reg2.support_ = find_support_vectors(svm_reg2, X, y)

eps_x1 = 1
eps_y_pred = svm_reg1.predict([[eps_x1]])
Output

Die Punkte außerhalb des \(\varepsilon\)-Bandes werden als relevante Punkte markiert.

5.2.2 Analyse und Zusammenfassung

Wichtig ist, dass die Breite der Toleranzzone von \(\epsilon\) abhängt. Ein kleineres \(\epsilon\) macht das Modell empfindlicher, ein größeres \(\epsilon\) toleriert mehr Abweichung [web:57][web:94].

Wichtig: Der Parameter C steuert die Stärke der Bestrafung, \(\epsilon\) steuert die erlaubte Abweichung um die Regressionslinie.
Python 
def plot_svm_regression(svm_reg, X, y, axes):
    x1s = np.linspace(axes[0], axes[1], 100).reshape(100, 1)
    y_pred = svm_reg.predict(x1s)
    plt.plot(x1s, y_pred, "k-", linewidth=2, label=r"$\hat{y}$")
    plt.plot(x1s, y_pred + svm_reg.epsilon, "k--")
    plt.plot(x1s, y_pred - svm_reg.epsilon, "k--")
    plt.scatter(X[svm_reg.support_], y[svm_reg.support_], s=180, facecolors='#FFAAAA')
    plt.plot(X, y, "bo")
    plt.xlabel(r"$x_1$", fontsize=18)
    plt.legend(loc="upper left", fontsize=18)
    plt.axis(axes)
Output

5.3 Problem 2: nichtlinear

Wenn der Zusammenhang gekrümmt ist, reicht die lineare SVR nicht mehr aus. Dann braucht man Kernel-Methoden wie poly oder rbf [web:92][web:66].

Python 
np.random.seed(42)
m = 100
X = 2 * np.random.rand(m, 1) - 1
y = (0.2 + 0.1 * X + 0.5 * X**2 + np.random.randn(m, 1)/10).ravel()

plt.scatter(X, y);
Output

5.3.1 Lösungsweg: Poly-Kernel

Mit dem Polynomial-Kernel kann die SVR einen gekrümmten Zusammenhang approximieren. Die Parameter degree, C und epsilon steuern die Anpassung [web:66][web:94].

Python 
from sklearn.svm import SVR

svm_poly_reg1 = SVR(kernel="poly", degree=2, C=100, epsilon=0.1, gamma="scale")
svm_poly_reg2 = SVR(kernel="poly", degree=2, C=0.01, epsilon=0.1, gamma="scale")
svm_poly_reg1.fit(X, y)
svm_poly_reg2.fit(X, y)
Output

Ein großes C passt sich stärker an, ein kleines C glättet stärker.

5.3.2 Analyse: Poly-Kernel

Der Polynomial-Kernel ist dann sinnvoll, wenn eine einfache lineare Regression den Verlauf nicht mehr gut beschreibt.

Python 
fig, axes = plt.subplots(ncols=2, figsize=(9, 4), sharey=True)

plt.sca(axes[0])
plot_svm_regression(svm_poly_reg1, X, y, [-1, 1, 0, 1])
plt.title(r"$degree={}, C={}, \epsilon = {}$".format(
    svm_poly_reg1.degree, svm_poly_reg1.C, svm_poly_reg1.epsilon), fontsize=18)
plt.ylabel(r"$y$", fontsize=18, rotation=0)

plt.sca(axes[1])
plot_svm_regression(svm_poly_reg2, X, y, [-1, 1, 0, 1])
plt.title(r"$degree={}, C={}, \epsilon = {}$".format(
    svm_poly_reg2.degree, svm_poly_reg2.C, svm_poly_reg2.epsilon), fontsize=18)
plt.show()
Output
Zusammenfassung: Der Poly-Kernel erlaubt eine bessere Anpassung an gekrümmte Verläufe, wobei C und epsilon die Form und Robustheit des Modells maßgeblich beeinflussen.

5.3.3 Lösungsweg: RBF-Kernel

Alternativ kann der RBF-Kernel verwendet werden. Er ist besonders flexibel und eignet sich sehr gut für nichtlineare Regression [web:66][web:92].

Python 
svm_reg1 = SVR(kernel="rbf", C=100, epsilon=0.1)
svm_reg2 = SVR(kernel="rbf",  C=0.01, epsilon=0.1)
svm_reg1.fit(X, y)
svm_reg2.fit(X, y)
Output

Der RBF-Kernel modelliert auch stark gekrümmte Zusammenhänge.

5.3.4 Analyse: RBF-Kernel

Der RBF-Kernel ist eine starke Standardwahl, wenn die Struktur der Daten nicht durch eine Gerade oder ein Polynom niedrigen Grades gut beschrieben werden kann [web:66][web:92].

Python 
fig, axes = plt.subplots(ncols=2, figsize=(9, 4), sharey=True)

plt.sca(axes[0])
plot_svm_regression(svm_reg1, X, y, [-1, 1, 0, 1])
plt.title(r"$C={}, \epsilon = {}$".format(svm_reg1.C, svm_reg1.epsilon), fontsize=18)
plt.ylabel(r"$y$", fontsize=18, rotation=0)

plt.sca(axes[1])
plot_svm_regression(svm_reg2, X, y, [-1, 1, 0, 1])
plt.title(r"$C={}, \epsilon = {}$".format(svm_reg2.C, svm_reg2.epsilon), fontsize=18)
plt.show()
Output
Endergebnis: SVR kann linear und nichtlinear eingesetzt werden. Die wichtigsten Stellschrauben sind C, epsilon und der gewählte Kernel.
