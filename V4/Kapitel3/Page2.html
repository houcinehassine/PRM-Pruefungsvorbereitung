SVM als Klassifikator & Maximum Margin

Auf dieser Seite bearbeiten wir einen Datensatz als Klassifikationsproblem, zeichnen verschiedene Trennlinien, führen den Begriff des Margins ein und leiten das Optimierungsproblem der SVM her.

2D-Feature-Raum Mehrere Trennlinien Margin maximieren SVC fitten Support Vectors Mathematische Herleitung

Lernfokus dieser Seite

Nach dieser Seite kannst du:

  • einen einfachen 2D-Datensatz mit SVM klassifizieren
  • einordnen, warum es viele mögliche Trennlinien gibt
  • verstehen, was ein maximaler Margin mathematisch bedeutet
  • die Entscheidungsfunktion und Support Vectors in sklearn nutzen

2.1 Daten als Klassifikator bearbeiten

Ausgangspunkt ist ein einfacher Datensatz mit zwei Klassen in einem 2D-Feature-Raum, die wir mit einem Klassifikator trennen wollen.

Python 
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs

X, y = make_blobs(
    n_samples=100,
    centers=2,
    random_state=2,
    cluster_std=1.2
)

plt.scatter(
    X[:, 0], X[:, 1],
    c=y, s=50,
    cmap='autumn',
    edgecolors='gray'
);
Output
Interpretation: Jede Farbe entspricht einer Klasse. Ziel ist es, eine Funktion zu lernen, die neuen Punkten die richtige Klasse zuweist.

2.2 Viele mögliche Trennlinien

Im linearen Fall gibt es in der Regel sehr viele Geraden, die zwei trennbare Klassen korrekt separieren – doch sie generalisieren nicht alle gleich gut auf neue Datenpunkte.

Wir zeichnen ein paar Beispiele für Geraden, die unsere Klassen trennen. Alle trennen die Trainingsdaten korrekt, führen aber bei neuen Datenpunkten zu unterschiedlichen Klassifikationen.

Python 
import matplotlib.pyplot as plt
import numpy as np

xfit = np.linspace(-3, 2)

plt.scatter(
    X[:, 0], X[:, 1],
    c=y, s=50,
    cmap='autumn',
    edgecolors='gray'
)

for m, b in [[-1.5, -6],
             [0.5, -5],
             [-0.1, -5.5]]:
    plt.plot(xfit, m * xfit + b, '-k')

plt.xlim(-3, 2);
Output
Wichtige Frage: Alle drei Geraden separieren die Klassen auf den Trainingsdaten. Aber: Wie verhalten sie sich bei neuen Datenpunkten? Genau hier setzt die Idee der Margin-Maximierung an.

2.3 Margin maximieren

Anstatt nur eine beliebige Trennlinie zu wählen, führt die SVM einen Margin ein: einen Abstandsstreifen um die Gerade, der möglichst groß sein soll.

  • Um jede Gerade wird ein Margin (Rand/Spanne) gelegt.
  • Dieser Margin reicht jeweils bis zu den nächstliegenden Punkten der Klassen.
  • Die optimale Gerade ist die mit dem größten Margin.

\(\Rightarrow\) SVMs sind sogenannte Maximum Margin Estimators.

Python 
import matplotlib.pyplot as plt
import numpy as np

xfit = np.linspace(-3, 2)

plt.scatter(
    X[:, 0], X[:, 1],
    c=y, s=50,
    cmap='autumn',
    edgecolors='gray'
)

for m, b, d in [[-1.5, -6, 0.33],
                [0.5, -5, 0.55],
                [-0.1, -5.5, 0.2]]:
    yfit = m * xfit + b
    plt.plot(xfit, yfit, '-k')
    plt.fill_between(
        xfit,
        yfit - d, yfit + d,
        edgecolor='none',
        color='#AAAAAA',
        alpha=0.4
    )

plt.xlim(-3, 2);
Output
Idee: Von allen zulässigen Trennlinien wählt die SVM genau diejenige, deren Margin zu den nächsten Punkten beider Klassen maximal ist.

2.4 Fitting / Training mit SVC

In sklearn verwenden wir für Klassifikation den Support Vector Classifier (SVC).

  • Wir instanziieren das SVM-Modell mit SVC(kernel=<kernel_type>, C=<regularization_parameter_value>).
  • kernel und C definieren die Art der Entscheidungsgrenze und die Regularisierung (Details später).
  • Mit der Methode .fit(X, y) passen wir das Modell an unsere Trainingsdaten an.
  • Das Ergebnis ist eine Trennlinie mit maximalem Margin, die die Klassen bestmöglich separiert.
  • SVC steht für Support Vector Classifier. SVMs können aber auch regressiv (SVR) verwendet werden.
Merke: Die SVC-Variante implementiert genau die Maximum-Margin-Idee für Klassifikationsaufgaben auf Basis eines geeigneten Kernels.

2.5 Support Vectors

Support Vectors sind die Schlüsselpunkte der SVM – nur sie bestimmen die endgültige Lage der Entscheidungsgrenze.

  • Diese Support Vectors sind die Punkte, die den Margin berühren.
  • Der Fit des Modells hängt nur von diesen Punkten ab.
  • Alle anderen Trainingspunkte haben keinen direkten Einfluss auf die Position der Trennlinie.
  • Über das Attribut .support_vectors_ können wir in sklearn auf sie zugreifen.
Intuition: Entfernt man einen Nicht-Support-Vector, ändert sich das Modell nicht. Entfernt man einen Support Vector, verschiebt sich die Trennlinie.

2.6 Mathematische Herleitung der SVM

Nun formulieren wir die SVM als Optimierungsproblem: Wir suchen die Hyperebene mit maximalem Margin zwischen zwei Klassen.

1. Datensatz

Wir betrachten einen binären Trainingsdatensatz \(\{(\mathbf{x}_i, y_i) \mid i = 1, \dots, N, y_i \in \{-1, 1\}\}\). Anhand dieser Daten lernen wir unsere Hyperebene.

Die Hyperebene wird beschrieben durch den Normalenvektor \(\mathbf{w}\) und den Bias \(b\). Zusammen definieren sie eindeutig eine Hyperebene im Raum.

2. Datenpunkte

Für Datenpunkte, die auf der Hyperebene liegen, gilt: \[ \langle \mathbf{w}, \mathbf{x}_i \rangle + b = 0 \] Für Punkte auf unterschiedlichen Seiten der Hyperebene wird dieser Ausdruck positiv bzw. negativ.

Trennt eine Hyperebene die Daten, dann haben alle Punkte einer Klasse das gleiche Vorzeichen: \[ y_i = \text{sgn}(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \quad\text{(Modellvorhersage)} \] oder äquivalent: \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 0 \]

Unter allen möglichen Hyperebenen wählen wir nun diejenige, die den größten Margin zwischen den beiden Klassen hat.

3. Margin – maximaler Margin

Der Margin ist der Abstand der Hyperebene zu den nächstgelegenen Datenpunkten beider Klassen. Sei \(r\) dieser Abstand, dann schreiben wir: \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge r \]

Wir formulieren ein Optimierungsproblem: \[ \max_{\mathbf{w}, b} \; r \] unter den Nebenbedingungen: \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge r, \quad \|\mathbf{w}\| = 1, \quad r > 0 \]

4. Normalenvektor und Umformung

Wir betrachten nun den Fall, dass der Normalenvektor nicht normiert ist. Durch geeignete Skalierung der Daten können wir die Bedingung \[ \langle \mathbf{w}, \mathbf{x}_a \rangle + b = 1 \] für den nächstliegenden Punkt \(\mathbf{x}_a\) (Support Vector) erzwingen. Dann lässt sich zeigen: \[ r = \frac{1}{\|\mathbf{w}\|} \]

Für die Nebenbedingung erhalten wir dann: \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 1 \] und unser Optimierungsproblem reduziert sich auf: \[ \max_{\mathbf{w}, b} \frac{1}{\|\mathbf{w}\|} \quad \text{bzw.} \quad \min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \] unter der Bedingung: \[ y_i(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \ge 1 \]

Kernidee: Durch Minimierung von \(\tfrac{1}{2}\|\mathbf{w}\|^2\) unter den linearen Nebenbedingungen erhalten wir eine Maximum-Margin-Hyperebene, also genau die SVM-Lösung.

2.7 Theorie in Python: Entscheidungsfunktion & Support Vectors

Zum Schluss setzen wir die mathematische Idee in Code um: Wir trainieren eine lineare SVC und visualisieren Entscheidungsgrenze, Margins und Support Vectors.

Python 
def plot_svc_decision_function(model, ax=None, plot_support=True):
    """Plot the decision function for a 2D SVC"""
    if ax is None:
        ax = plt.gca()
    xlim = ax.get_xlim()
    ylim = ax.get_ylim()

    # create grid to evaluate model
    x = np.linspace(xlim[0], xlim[1], 30)
    y = np.linspace(ylim[0], ylim[1], 30)
    Y, X = np.meshgrid(y, x)
    xy = np.vstack([X.ravel(), Y.ravel()]).T
    P = model.decision_function(xy).reshape(X.shape)

    # plot decision boundary and margins
    ax.contour(
        X, Y, P,
        colors='k',
        levels=[-1, 0, 1],
        alpha=0.5,
        linestyles=['--', '-', '--']
    )

    # plot support vectors
    if plot_support:
        ax.scatter(
            model.support_vectors_[:, 0],
            model.support_vectors_[:, 1],
            s=300, linewidth=1,
            facecolors='none'
        )
    ax.set_xlim(xlim)
    ax.set_ylim(ylim)

# Ploten:
fig, axi = plt.subplots(1, 1)

from sklearn.svm import SVC

model = SVC(kernel='linear').fit(X, y)
axi.scatter(
    X[:, 0], X[:, 1],
    c=y, s=50,
    cmap='autumn',
    edgecolors='gray'
)
plot_svc_decision_function(model, axi)
axi.scatter(
    model.support_vectors_[:, 0],
    model.support_vectors_[:, 1],
    s=300, lw=1,
    facecolors='none',
    edgecolors='blue'
)
# axi.set_title('C = {0:.1f}'.format(C), size=14)
Output
Lesen der Grafik: Die durchgezogene Linie ist die Entscheidungsgrenze (Level 0), die gestrichelten Linien markieren die Margin-Ränder (Level ±1) und die markierten Punkte sind die Support Vectors.
