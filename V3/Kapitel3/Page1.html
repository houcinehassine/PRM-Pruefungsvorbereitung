1. Was ist Klassifikation?

Klassifikation bedeutet, dass ein Modell eine Eingabe einer vordefinierten Klasse zuordnet.

Eingabe

Ein Datensatz besteht aus Merkmalen, zum Beispiel Größe, Gewicht oder Pixelwerten.

Ausgabe

Das Modell gibt ein Label zurück, zum Beispiel 0 oder 1.

2. Einfaches Beispiel

Hier siehst du ein kleines Beispiel, wie Klassifikationsdaten aussehen können.

Python 
from sklearn.datasets import make_blobs

X, y = make_blobs(
    n_samples=100,
    centers=2,
    random_state=2,
    cluster_std=1.2
)

print("Shape von X:", X.shape)
print("Klassen:", set(y))
Output 
Shape von X: (100, 2)
Klassen: {0, 1}

3. Warum SVM?

Support Vector Machines sind interessant, weil sie eine Trennlinie mit großem Abstand zwischen den Klassen suchen.

SVM

Idee

Die SVM sucht eine Hyperplane, die die Klassen möglichst gut trennt.

+

Support Vectors

Die wichtigsten Punkte sind die Datenpunkte nahe an der Trennlinie.
