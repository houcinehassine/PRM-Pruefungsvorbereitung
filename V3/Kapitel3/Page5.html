PRM Kapitel 3 – Python-Umsetzung, Loss-Funktion und Gradientenabstieg

Seite 5: Umsetzung der SVM von der Kostenfunktion bis zum Training

1. Idee der Umsetzung

Nachdem die SVM mathematisch formuliert wurde, wird sie in Python als Loss Function und Trainingsalgorithmus umgesetzt.

Ziel ist es, die Kostenfunktion in Python abzubilden und anschließend die Parameter w und b durch Gradientenabstieg zu optimieren.

2. Loss Function

Die Kostenfunktion kombiniert den Regularisierungsterm mit der Hinge Loss. Sie misst also einerseits die Größe des Gewichtsvektors und andererseits, wie stark Margin-Verletzungen auftreten.

loss = 1/2 * ||w||^2 + C * mean(max(0, 1 - y(⟨w, x⟩ + b)))

Damit wird die SVM in eine Form gebracht, die sich numerisch optimieren lässt.

3. Python-Beispiel für die Loss Function

Im Skript wird die Funktion svm_loss_function umgesetzt. Sie berechnet zunächst die Penalties und daraus die Hinge Loss.

def svm_loss_function(X, y, w, b, C): penalties = 1 - y * (np.dot(X, w) + b) penalties[penalties < 0] = 0 hinge_loss = C * np.mean(penalties) loss = 1 / 2 * np.dot(w, w) + hinge_loss return loss

Diese Funktion ist die Grundlage für das spätere Training.

4. Gradienten

Damit wir die Kostenfunktion minimieren können, brauchen wir die Ableitungen nach w und b.

Die Gradienten werden abhängig davon bestimmt, ob ein Punkt den Margin verletzt oder nicht.

def svm_gradients(X, y, w, b, C): m = X.shape[0] margins = 1 - y * (X.dot(w) + b) active = margins > 0 dw = w - (C / m) * (X[active].T.dot(y[active])) db = -(C / m) * np.sum(y[active]) return dw, db

Wenn kein Margin-Verstoß vorliegt, ist der Beitrag klein bzw. null. Wenn ein Verstoß vorliegt, werden die entsprechenden Punkte mit einbezogen.

5. Gradientenabstieg

Um die Parameter zu optimieren, wird ein einfacher Full-Batch Gradient Descent verwendet. Dabei werden pro Epoche die Gradienten über den gesamten Datensatz berechnet.

Δ = -∇Λ w(t+1) = w(t) + Δw b(t+1) = b(t) + Δb

Die Lernrate wird als lr bezeichnet. Sie bestimmt, wie groß die Updates pro Schritt sind.

6. Trainingsfunktion

Die Trainingsfunktion svm_train führt die Gradientenschritte über mehrere Epochen aus. Zusätzlich werden die Kostenwerte gespeichert, um den Lernfortschritt sichtbar zu machen.

def svm_train(X, y, w, b, C, lr, epochs): list_of_costs = [] for epoch in range(epochs): dw, db = svm_gradients(X, y, w, b, C) w -= lr * dw b -= lr * db list_of_costs.append(svm_loss_function(X, y, w, b, C)) return w, b, list_of_costs

Damit kann man das Modell trainieren und die Entwicklung der Loss-Werte später plotten.

7. Lernfortschritt visualisieren

Die Liste der Kostenwerte kann geplottet werden, um zu zeigen, wie das Training über die Epochen verläuft. So wird sichtbar, ob das Modell konvergiert.

plt.plot(list_of_costs) plt.xlabel('Epochs') plt.ylabel('Loss')

Das ist besonders hilfreich, um zu prüfen, ob die Trainingsparameter sinnvoll gewählt wurden.

8. Entscheidungsgerade anzeigen

Für die Visualisierung der trainierten SVM wird aus den Parametern w und b eine Entscheidungsgerade gezeichnet.

Damit die Darstellung korrekt funktioniert, wird der Gewichtsvektor normalisiert.

def plot_decision_line(w, b, x_range): fig, ax = plt.subplots(figsize=(6,5)) xmin, xmax = x_range xs = np.linspace(xmin, xmax, 400) norm = np.linalg.norm(w) w = w / norm ys = -(w[0] * xs + b) / w[1] ax.plot(xs, ys, linewidth=2, label='decision line') ax.set_xlabel('x1') ax.set_ylabel('x2') ax.legend() ax.grid(True) return ys

Damit lässt sich die gelernte Hyperebene direkt im Feature-Raum anzeigen.

9. Was du hier verstehen musst

  • Die Loss Function misst Regularisierung und Margin-Verletzungen.
  • Die Hinge Loss ist der zentrale Fehlerterm.
  • Die Gradienten werden separat nach w und b berechnet.
  • Das Training erfolgt mit Gradient Descent.
  • lr ist die Lernrate, epochs die Anzahl der Trainingsdurchläufe.
  • Die Trainingskurve zeigt, ob das Modell besser wird.
