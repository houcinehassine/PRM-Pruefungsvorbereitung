PRM Kapitel 3 – Hard- und Soft-Margin

Seite 4: C, Slack Variable, Hinge Loss und Regularisierung

1. Hard- und Soft-Margin

Bei SVMs kann man den Margin entweder hart oder weich definieren. Das bedeutet: Man kann zulassen, dass Datenpunkte innerhalb des Margins liegen.

Die Leitfrage lautet: Wie viele Punkte dürfen den Margin verletzen und in welchem Ausmaß?

Dafür verwendet man den Hyperparameter C. Große Werte entsprechen eher einem Hard-Margin, kleine Werte eher einem Soft-Margin.

2. Bedeutung von C

Der Wert von C muss passend zum Datensatz gewählt werden, zum Beispiel mithilfe von Cross-Validation.

In sklearn taucht dieser Parameter direkt im SVC-Modell auf:

SVC(kernel=, C=)
Merksatz: C steuert den Trade-off zwischen großer Margin und Fehlertoleranz.

3. Slack Variable

Um Margin-Verletzungen zu erlauben, wird eine Slack Variable eingeführt. Sie bestraft Punkte, die innerhalb des Margins liegen oder auf der falschen Seite der Grenze sind.

Dadurch werden Verletzungen des Margins zugelassen, aber nicht kostenlos. Genau das macht die Soft-Margin-SVM möglich.

Wichtig: Ohne Slack Variable wäre die SVM viel strenger und würde nur perfekt trennbare Daten akzeptieren.

4. Regularisierung

Der Parameter C sorgt für einen Trade-off zwischen Größe des Margins und Verletzung des Margins.

Deshalb nennt man ihn auch Regularisierungsparameter. Margin-Maximierung ist damit selbst eine Form von Regularisierung.

5. Warum Accuracy nicht reicht

Eine naheliegende Loss Function wäre die Accuracy. Diese ist aber ungeeignet, weil sie ein kombinatorisches Optimierungsproblem erzeugt.

Stattdessen braucht man eine kontinuierliche Loss Function. Hier wird die Hinge Loss verwendet.

L(x) = max{0, 1 - y(⟨w, x⟩ + b)}

Die Hinge Loss bestraft vor allem Punkte, die den Margin verletzen oder falsch klassifiziert sind.

6. Optimierungsziel

Aus Margin-Maximierung und Hinge Loss ergibt sich das endgültig optimierbare Problem.

min 1/2 ||w||^2 + C * mean(max(0, 1 - y(⟨w, x⟩ + b)))

Das Ziel ist also: eine große Margin erhalten, aber Margin-Verletzungen kontrolliert zulassen.

7. Interpretation von C

C-Wert Interpretation Folge für das Modell
Groß Hard-Margin-artiges Verhalten Weniger Toleranz für Verletzungen
Klein Soft-Margin-artiges Verhalten Mehr Toleranz für Verletzungen

8. Was du hier verstehen musst

  • Hard-Margin bedeutet strenge Trennung.
  • Soft-Margin erlaubt Verletzungen des Margins.
  • C steuert den Ausgleich zwischen Margin und Fehlertoleranz.
  • Die Slack Variable bestraft Verletzungen.
  • Die passende Loss Function ist die Hinge Loss.
  • Die SVM ist damit ein regularisiertes Optimierungsproblem.
